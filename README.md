# RAG PROJECT

**The porpuse of this project is practice the process of RAG using OPENAI LLM. I divided the project in four different files in which we use diferent 
methods from plain text until using vector local database**

1. Step 1 - Prepare your text of documents
2. Step 2 - Splitting the data into chunks
3. Step 3 - Create embeddings for chunks
4. Step 4 - Create and store the embeddings in vector store
5. Similiraty Search

### Extra steps

1. Talk with LLM
2. Store the vector DB in local machine
3. Using the vector DB from the local machine instead of the vector DB IN-MEMORY
4. Add more information (text, new documents , etc) in existing vector DB

**In this file introduce the use of langchain and we use plain text**

## 2.0 Rag_PDF
